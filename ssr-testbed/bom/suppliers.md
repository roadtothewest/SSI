# Proveedores

## Electrónicos (Recomendados)

| Proveedor     | Web                          | Ideal para              |
|---------------|------------------------------|------------------------|
| Mouser        | mouser.com                   | Componentes STM, ST, TI, Murata. Envío rápido (~3-5 días) |
| Digikey       | digikey.com                  | Similar a Mouser, buena disponibilidad de conectores JST |
| LCSC          | lcsc.com                     | Pasivos, conectores, más barato pero China (~2 semanas) |
| AliExpress    | aliexpress.com                | Breakout boards baratos (INMP441), cables dupont |
